# Pruebas automatizadas

## Metodología Arrange-Act-Assert
1. Arrange: preparar el escenario.
2. Act: ejecutar el comportamiento.
3. Assert: verificar el resultado.

## Casos normales y límite
- Cubrir al menos un caso normal y los casos límite relevantes.

## Ejecución de tests
- Ejecutar los tests mediante la herramienta bash.

## Reporte de bugs
- Describir: pasos, resultado esperado, resultado real, entorno.
