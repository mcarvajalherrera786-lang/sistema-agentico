# Código limpio

## Estándares de codificación
- Nombres claros y consistentes.
- Sin duplicación; extraer fragmentos repetidos.

## Tipado estricto
- Tipar explícitamente los datos críticos.
- Evitar `any` cuando se pueda evitarlo.

## Manejo explícito de errores
- No silenciar errores.
- Propagar o convertir con contexto claro.

## Funciones pequeñas
- Una función = una responsabilidad.
- Si excede límites, dividir.

## Docstrings claros
- Documentar propósito, parámetros y salida.
